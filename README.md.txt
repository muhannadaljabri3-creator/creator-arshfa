مشروع أرشفة - النسخة التأسيسية العربية

محتويات المشروع:
- index.html: هيكل الواجهة العربية.
- styles.css: التصميم الحكومي الرسمي.
- renderer.js: تفاعل الواجهة وقائمة الملفات والمراجعة والإعدادات.
- main.js و preload.js: ربط Electron واختيار المجلدات ومراقبة مجلد السكنر ونسخ الملفات بعد اعتمادها.
- package.json: إعدادات Node.js و Electron.

طريقة التشغيل:
1) ثبّت Node.js LTS على Windows.
2) فك ضغط المشروع في مجلد ثابت.
3) افتح Terminal أو CMD داخل مجلد المشروع.
4) نفّذ:
   npm install
5) بعد اكتمال التثبيت نفّذ:
   npm start

إنشاء ملف تثبيت Windows:
   npm run dist

مهم جداً - حدود هذه النسخة:
هذه نسخة تأسيسية للواجهة وسير استقبال الملفات ومراقبة مجلد السكنر والمراجعة اليدوية ونسخ الملف إلى الأرشيف بعد اعتماد المستخدم.
محرك OCR العربي لم يُربط بعد، لذلك لا تقرأ هذه النسخة النص العربي تلقائياً ولا تستخرج العدد/الموضوع/الاسم آلياً حتى الآن.
كما أن فصل كتاب متعدد الصفحات من PDF مجمع آلياً غير مفعّل بعد؛ يلزم بناء وحدة تحليل حدود الكتب وفصل PDF وربطها بمحرك OCR واختبارها على نماذج حقيقية قبل تشغيل الأرشفة التلقائية.
لا تحذف ملفات السكنر الأصلية هذه النسخة؛ تحفظ نسخة في مجلد الأرشيف عند اعتماد المراجعة.
يفضل تجربة البرنامج أولاً على نسخ من ملفات غير حساسة وليس على الأرشيف الأصلي.

الأمان:
- Node integration معطل داخل صفحة الواجهة.
- التواصل مع وظائف النظام يتم عبر preload.js و IPC.
- لا تضع ملفات كتب سرية في نسخة تجريبية قبل مراجعة إعدادات الأمان والنسخ الاحتياطي.
