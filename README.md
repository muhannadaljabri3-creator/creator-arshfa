# أرشفة الكتب والمخاطبات

تطبيق سطح مكتب عربي مبني باستخدام Electron وNode.js لاستقبال ملفات السكنر، وقراءة النص العربي آلياً، ثم مراجعة البيانات وأرشفة نسخة من الملف.

## المتطلبات

- Windows 10 أو 11.
- Node.js 22.13 أو أحدث وnpm.
- لا يحتاج OCR العربي إلى تنزيل بيانات إضافية عند أول تشغيل؛ بيانات اللغة تأتي ضمن المشروع.

## التشغيل والاختبار

افتح Terminal داخل مجلد المشروع ونفّذ:

```sh
npm install
npm start
```

لتشغيل الاختبارات:

```sh
npm test
```

لبناء مثبت Windows:

```sh
npm run dist
```

## سير العمل

1. اختر مجلد السكنر ومجلد الأرشيف من الإعدادات.
2. شغّل مراقبة مجلد السكنر أو استورد ملفاً يدوياً.
3. يحاول OCR قراءة العدد والتاريخ والموضوع والموظف.
4. راجع البيانات المقترحة وعدّلها قبل الحفظ.
5. يحفظ التطبيق نسخة في الأرشيف ولا يحذف الملف الأصلي.

يدعم إدخال PDF وJPG/JPEG وPNG وTIF/TIFF وBMP وGIF وWebP وAVIF. تُحوّل الصور إلى PNG قبل OCR، وتعالج الصور متعددة الصفحات حتى 100 صفحة. PDF يعالج صفحته الأولى فقط في هذه النسخة. يحاول استخراج الموضوع واسم الموظف من الحقول ذات العناوين أو من القوائم التي تضيفها في الإعدادات؛ راجع نتائج OCR دائماً.

هذه نسخة اختبارية: ملفات الأرشيف تبقى في مجلدها، لكن سجل الملفات والمراجعات داخل التطبيق لا يُحفظ بعد إغلاق البرنامج. اختبر أولاً على نسخ غير حساسة من ملفاتك.
